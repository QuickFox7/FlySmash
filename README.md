# Fly Smash

ハエをクリックしてスコアを伸ばし、ロケットを上昇させてハイスコアを目指すブラウザゲームです。

PC・スマートフォンの両方で遊べる、HTML・CSS・JavaScript で制作したゲームです。

## ゲーム概要

画面上を動き回るハエをクリックして倒すと、スコアが上昇します。
連続してハエを倒すとコンボが発生し、演出とともにゲームを楽しめます。

画面下部にはロケットが表示され、スコアの変動に合わせて上昇・下降します。
風や星、ズームなどの演出によって、ロケットの飛行を表現しています。

また、サバイバルモードではハエを放置するとスイカを食べられてしまうため、素早くハエを倒すことが重要です。

## ゲームモード

### 1. エンドレス（Endless）

- 時間制限なしでプレイできます。
- ハエを倒してスコアを伸ばします。
- どこまでスコアを伸ばせるか挑戦するモードです。

### 2. 60秒チャレンジ（Time Attack）

- 制限時間は60秒です。
- 時間内にできるだけ高いスコアを目指します。
- 残り時間は円形のタイマーで表示されます。
- 終了後はリザルト画面でスコアを確認できます。

### 3. サバイバル（Survival）

- ライフは3つです。
- ハエがスイカを食べきるとライフが1つ減ります。
- 一定時間ごとにハエの襲来イベントが発生します。
- 襲来中は最大5匹のハエがスイカに向かって移動します。
- 襲来イベント中に15匹倒すとクリアです。
- ライフがなくなるとゲーム終了です。

## 操作方法

### ハエを倒す

- PC：マウスでハエをクリックします。
- スマートフォン：画面上のハエをタップします。

### ロケットを操作する

ハエをクリック・タップしてスコアの上昇速度を変化させ、ロケットを上昇させます。

スコアは時間経過によって変化するため、クリックのタイミングが重要です。

### その他の操作

- モード選択画面の左右の矢印でゲームモードを切り替えます。
- START ボタンでゲームを開始します。
- HOME ボタンでタイトル画面に戻ります。

## 主な機能

- 3種類のゲームモード
- ランダムに移動するハエ
- 複数回のクリックが必要な強いハエ
- 強いハエの体力ゲージ
- コンボ表示と演出
- 猫の手による攻撃演出
- スイカの果汁エフェクト
- スイカを食べるハエのゲージ表示
- サバイバルモードの襲来イベント
- ロケットの上昇・下降
- 星や風のエフェクト
- スコア・ハイスコアの表示
- ゲーム終了後のリザルト画面
- PC・スマートフォン向けのレイアウト調整
- スマートフォンでの画像長押しや意図しない拡大操作への対策

## 使用技術

- HTML5
- CSS3
- JavaScript
- Canvas API
- SVG

外部ライブラリやゲームエンジンを使用せず、ブラウザ標準の機能を中心に実装しています。
